# 用喜歡的音訊做影子跟讀的方法

<p class="lead">影子跟讀（shadowing）是不暫停播放中的音訊，稍微慢一點、像影子一樣跟在後面說出來的練習。這裡整理了基本步驟，以及不用專門教材、而是用自己喜歡的音訊來練習的方法。</p>

## 影子跟讀的基本步驟

一開始就直接跟著音訊說，常常會嘴巴跟不上而半途而廢。按照以下順序進行，會比較容易上手。

1. 先不看文字，從頭到尾聽一遍，確認自己能聽懂多少
2. 對照文字確認。用文字確認沒聽懂的地方，並查詢不懂意思的詞
3. 一邊看文字一邊跟著說，和音訊同時朗讀（[同步跟讀](/zh-hant/guides/overlapping)）
4. 不看文字跟著說。把文字隱藏起來，稍微慢一點模仿聽到的聲音。這就是影子跟讀
5. 只重練卡住的句子。回到說不出來的句子，用較慢的速度反覆練習

反覆練習 1～2 分鐘左右的短音訊，會比較容易持續。覺得太快的話，就先放慢速度開始吧。

## 用喜歡的音訊練習時會遇到的困難

影子跟讀用的教材附有文稿，也切分成容易練習的段落。但平常聽的 Podcast 或課程錄音就沒有這些。

- 想回到說不出來的那一句，用進度條卻很難精準跳到開頭
- 沒有文字，無法確認沒聽懂的聲音是什麼
- 速度太快時，一般的播放器無法細微調整速度

## 用 Reprise 做影子跟讀

Reprise 是一款語言學習播放器，會在 iPhone 上轉錄匯入的音訊，並自動逐句切分。上面的步驟可以直接在同一個畫面中完成。

1. 匯入音訊。從「+」選擇 Podcast、檔案、錄音或貼上的文字。匯入後會自動逐句切分
2. 把播放方式設為「連續播放」，從頭到尾聽一遍。文字可以用操作面板最左邊的眼睛按鈕隱藏
3. 對照文字確認。只有在長按眼睛按鈕時才會顯示文字。沒聽懂的句子，點按就能從開頭重聽
4. 跟著音訊說。速度可以在 0.5～2.0 倍之間調整（音調不變）。先從 0.8 倍左右開始
5. 反覆練習卡住的句子。把播放方式設為「單句循環」，就會只重複那一句。把句子向右滑動加入書籤，之後就能集中複習（複習功能需 Reprise Premium）

句子太長、不好跟的時候，可以用「…」→「重新分句」，選擇「按片語」或「按意群」切得更細。

## 常見問題

### 沒有文稿的音訊也能練習嗎？

可以。轉錄由 iPhone 上的語音辨識完成。有時會出錯，可以長按句子修改文字。

### 英文以外的語言也可以嗎？

支援英文（美國、英國、澳洲）、日文、中文（簡體）、韓文、法文、德文與西班牙文。

### 可以確認自己的聲音嗎？

長按句子並選擇「清晰度檢測」，就能錄下你朗讀該句的聲音，逐詞確認裝置上的語音辨識是怎麼聽的。免費用戶在每個音軌中可任選 3 句使用（使用 Reprise Premium 則所有句子都能使用）。說完後錄音會自動停止並進入下一回，可以連續練習。這不是發音評分，而是用來確認你想說的話有沒有傳達出去的參考。
