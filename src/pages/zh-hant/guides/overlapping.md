# 同步跟讀的練習方法

<p class="lead">同步跟讀（overlapping）是一邊看文字（文稿），一邊和音訊完全重疊說出來的練習。這是模仿連音與節奏的練習，也常被當作影子跟讀之前的準備階段。</p>

## 同步跟讀的步驟

1. 確認文字的意思。先查好不懂的詞和句型
2. 和音訊同時朗讀。不要落後也不要搶快，與音訊重疊
3. 反覆練習對不上的句子。回到中途跟不上的句子，只練那一部分
4. 能輕鬆重疊之後，就提高速度，試試原速，再試試稍快一點的速度

## 需要準備的東西

同步跟讀需要音訊和它的文字。沒有附文字的音訊，無法直接拿來練習。

## 用 Reprise 做同步跟讀

Reprise 會在 iPhone 上轉錄匯入的音訊。這份轉錄文字可以當作台詞本使用。

1. 匯入音訊。音訊會逐句切分，並附上文字
2. 把播放方式設為「連續播放」。正在播放的句子會亮起來，可以一邊用眼睛追著看，一邊跟著說
3. 對不上的句子，點按就能從開頭重聽，或用「單句循環」反覆練習
4. 速度可以在 0.5～2.0 倍之間調整，音調不變

轉錄有時會出錯。發現錯誤時，請長按句子，從「調整此句」修改文字。

手邊只有文字、沒有音訊時，可以用「從文字建立」貼上文字，用裝置上的聲音朗讀並產生音訊。這樣文字和音訊就會完全一致。

## 下一步的練習

能重疊之後，就隱藏文字，進階到[影子跟讀](/zh-hant/guides/shadowing)吧。
