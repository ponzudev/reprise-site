# 手持ちの音声でディクテーションするやり方

<p class="lead">ディクテーションは、聞こえた文をそのまま書き取る練習です。どの音が聞き取れていないかが、はっきり分かります。</p>

## ディクテーションの手順

1. 一文を聞きます。長い音声は一文かそれより短く区切ります
2. 聞こえたとおりに、紙やメモアプリへ書き取ります
3. 書けなかったところを何度か聞き直します
4. 答え合わせをします。本文と見比べ、聞き取れなかった理由（知らない語、音のつながり、速さ）を確かめます
5. 最後に本文を見ながら声に出すと、次に聞いたときに聞き取りやすくなります

## Reprise でディクテーションする

Reprise には書き取りを入力する画面はありません。紙やメモアプリと組み合わせて使います。

1. 音声を取り込み、文ごとに区切ります
2. 操作パネル左端の目のボタンで本文を伏せます
3. 再生スタイルを「1 文をループ」にします。同じ文が間を挟んで繰り返されます。聞きながら書き取ります
4. 書けたら、伏せるボタンを長押しします。押している間だけ本文が出るので、その場で答え合わせができます
5. 「次の文」で進みます

一文が長くて書ききれないときは、「⋯」→「文分割をやり直す」で「フレーズごと」「チャンクごと」に細かく区切り直せます。速すぎるときは、速度を 0.5 倍まで落とせます。

## 気をつけること

本文は iPhone の中の音声認識で書き起こしたものなので、間違いが含まれることがあります。答えがおかしいと感じたら、聞き直して確かめ、文を長押しして本文を直してください。正確な本文で練習したいときは、スクリプト付きの教材の音声を取り込むか、「文章から作る」で文章から音声を作る方法が向いています。
