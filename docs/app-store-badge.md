# App Store バッジ

`public/assets/app-store-badge-ja.svg` は日本語の黒い「App Store からダウンロード」バッジ。SVGの色・文字・縦横比は変更していない。

Apple配布ページへのネットワーク接続が制限されているため、公式バッジを再配布する `@rewilok/app-store-badges@0.1.3` の `assets/app_store_badge/black/ja.svg` をそのまま取得した。パッケージのコードは導入していない。

- 配布パッケージ: https://www.npmjs.com/package/@rewilok/app-store-badges
- 配布元: https://github.com/rewilok/app-store-badges
- npm integrity: `sha512-86r24xmhIeFSeyL/0+gXks+8qq4Q1OLo1gW4NkdSSJ3zC3NHdExoadbLjX1KlwBxyqYRoCM3FukeesRpuMXlxQ==`
- Apple ガイドライン: https://developer.apple.com/app-store/marketing/guidelines/

バッジの権利は Apple Inc. に帰属する。Apple、Appleロゴ、iPhone、iPad、App StoreはApple Inc.の商標またはサービスマーク。配布パッケージのApacheライセンスはバッジの図柄には適用されない。

表示は高さ40px以上、縦横比固定、周囲に高さの1/4以上の余白を確保。リンク先は既存のRepriseのApp Storeページ。
